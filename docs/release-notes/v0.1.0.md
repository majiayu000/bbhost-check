First release. One command to find what breaks when Bitbucket Cloud moves Git over SSH from `bitbucket.org` to `ssh.bitbucket.org`, and to rewrite it after you confirm.

Per the [official announcement](https://community.atlassian.com/forums/Bitbucket-articles/Upcoming-change-to-Bitbucket-Cloud-SSH-access-move-from/ba-p/3234032), SSH to `bitbucket.org` is blocked during brownout windows from **2026-11-12** and removed on **2026-12-10**. Per the [Bitbucket Cloud changelog of 2026-10-13](https://developer.atlassian.com/cloud/bitbucket/changelog/), from **2026-11-30** OAuth Git requests from **Git Credential Manager below 3.0.0** are blocked.

### What it checks

- Every repo under `--root`: remote `url` / `pushurl`, submodule URLs and `[url]` sections in `.git/config`, `.git/modules/*/config`, bare repos, `.gitmodules`
- Global and system git config
- `~/.ssh/config`: `Host bitbucket.org` blocks (their `IdentityFile` stops applying after the rename) and `HostName bitbucket.org` aliases
- `~/.ssh/known_hosts`, plain or hashed: missing `ssh.bitbucket.org` entry (the host keys did not change)
- CI: `bitbucket-pipelines.yml`, GitHub Actions, `.gitlab-ci.yml`, `Jenkinsfile*`, including `ssh-keyscan bitbucket.org`
- Manifests and lockfiles: npm, yarn, pnpm, Cargo, Go, Bundler, pyproject / requirements, Poetry, uv; npm `bitbucket:` shorthand is flagged for a manual change
- Git Credential Manager: reports GCM below 3.0.0 only when it is the credential helper git uses for `https://bitbucket.org`, OAuth is not disabled, and something actually reaches Bitbucket over HTTPS. Git for Windows still bundles GCM 2.9.x, so Windows users get the standalone GCM install steps

### Safe by default

- Read-only unless you pass `--fix`. `--fix` shows the diff, asks `[y/N]`, backs up each file and changes only the matched lines.
- Local files only. No Bitbucket token, no network calls, no credentials read. `https://` URLs are never changed.
- Output as text, JSON, or Markdown for a PR. Exit code `1` when findings remain, so it works as a CI check.

### Install

Download the archive for your platform below (Linux x86_64 static musl, macOS arm64 and x86_64; each has a `.sha256`), or:

```bash
cargo install bbhost-check
```
